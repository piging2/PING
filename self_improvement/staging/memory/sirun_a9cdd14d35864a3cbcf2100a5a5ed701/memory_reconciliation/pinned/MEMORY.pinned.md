## Windows Terminal flash root cause (2026-09-17, fixed)
* The persistent quick flashes were Windows Terminal windows, not powershell directly. Nolan has Windows Terminal set as default terminal; when a scheduled task launches powershell.exe (even with -WindowStyle Hidden), WT briefly creates a VISIBLE window (~300ms) before the hidden flag takes effect. Three tasks firing together = three simultaneous flashes.
* Process-based monitoring (MainWindowHandle on powershell.exe) MISSED it because the visible window belongs to WindowsTerminal.exe, not powershell.exe. Window-enumeration (EnumWindows) caught it.
* Fix deployed: all 7 Pigi tasks now launch via wscript.exe //B //Nologo hidden-launch.vbs (GUI-subsystem app, no console allocated, bypasses WT entirely). Verified live: triggered task ran exit 0 with zero WT windows.
