# Notes: cross-cutting Q1–Q4

Read 2026-09-30 (index).

## Q1 — Semrush vs Ahrefs topic-discovery → brief → publish; evidence vs ad-hoc
- Semrush workflow: Topic Research (domain or topic → geo database → content idea cards from crawled competitor sites → XLS export) → Keyword Magic/Topic Finder → SEO Content Template/brief (competitor analysis, keyword clusters, search intent) → AI draft / Writing Assistant → Content Optimizer (readability, tone, keyword scores) → WordPress one-click publish. (thetoolsverse, SEJ, marketingscoop, craigcampbellseo)
- Ahrefs workflow: Keywords Explorer (volume, KD, traffic potential, SERP features: featured snippets, PAA, AI Overviews) → Site Explorer competitor organic keywords/top pages → Content Gap (up to 3 competitors, "keywords they rank for but you don't"; filter ≥2 in top 10) → export. (onelittleweb, termui skill, xsquareseo)
- Evidence vs ad-hoc: HubSpot topic-cluster report (2017): 12,000+ posts restructured into pillar/cluster architecture → documented ranking improvements (via avelino.run blog; also medium @elenaghiban7).
- Kevin Indig / Growth Memo (cited in https://github.com/avelino/avelino.run/blob/HEAD/content/blog/2026-03-topical-authority-destination-before-ticket.md): pages with high topical authority gain traffic 57% faster than low-authority equivalents.
- Prop-firm case study (https://www.linkedin.com/pulse/prop-firm-affiliate-seo-case-study-145-clicks-3660-6-semantic-seo-kojzf): 145→3,660 clicks in 6 months (+2,424%), impressions 35k→653k (+1,766%), zero backlinks, ~90 topics across 3 sections, Koray Tugberk GUBUR topical-map methodology.
- ahrsumon case study (https://ahrsumon.com/case-study-mobile-app-seo-growth-topical-authority/): +97.75% clicks in one month (1,725→3,410), impressions +120.15%, before full map published.
- benskamps seo-superpower skill (https://github.com/benskamps/seo-superpower/blob/HEAD/skills/planning-topic-clusters/SKILL.md): claims clustered content ~30% more organic traffic, 3.2× AI citations, pillar citation rate 12%→41% w/ hub-and-spoke linking, 8-15 spokes sweet spot — treat as practitioner claim, weaker evidence.
- Honesty counter-note (https://github.com/youtube-jono/seo-agent/blob/HEAD/references/hub-spoke-pages.md): Google never endorsed topic clusters; underlying mechanism is internal linking + coverage; founding data = one 2015 HubSpot correlational experiment; "43% average traffic increase" stat traces to no primary study — do not cite.
- searchinsightsacademy.com (https://www.searchinsightsacademy.com/topic-clusters-pillar-pages/): cites HubSpot study of up to 50% organic traffic increase with proper implementation.

## Q2 — SparkToro modeling + data sources
- Data sources: (1) crawl of billions of web pages + social accounts → 70M+ profiles: bio text, job titles, words/phrases, hashtags, followed accounts, shared/linked websites; (2) search results + LinkedIn profiles; (3) Datos clickstream panel — tens of millions of real devices: website affinities, social-network engagement categories, search behavior; (4) podcast data: social mentions + clickstream visit estimates → listener estimates.
- Modeling: query defines audience ("follows @X", "bio contains Y", "talks about Z", "visits domain"); intersect matching profiles (Venn); affinity = over-representation vs average internet user; one vote per profile per site (no overweighting); confidence shown from sample size × behavior homogeneity (2-20% coverage typical); aggregate + anonymize, no PII.

## Q3 — developer content marketing evidence
- Ozigi blog 2026-08-14 (https://github.com/ozigi-app/ozigi/blob/HEAD/apps/blog/content/blog/developer-marketing.mdx): developers trust docs, working code, peers, search; distrust ads, gated content, superlatives, funnels. Works: excellent docs as marketing asset, honest technical content that ranks, genuinely usable free tier, presence where developers gather, outreach built on their public work. Fails: buzzwords, fake community engagement, gating, hype. Team-of-one playbook.
- growth-tools AFFiNE case study (https://github.com/gingiris-1031/growth-tools/blob/HEAD/_posts/2026-04-03-open-source-marketing-the-complete-guide.md): 0→60k GitHub stars in 18 months; no paid marketing; open-sourced early w/ excellent docs; organic HN launch; Reddit authentic discussion; channels that worked: GitHub README (=landing page), HN Show HN, niche subreddits, Dev.to/Hashnode, Discord/Slack, conference talks; what failed: paid Twitter ads ~0.4x return, generic awesome lists ~10 stars/6 months, r/programming inconsistent.
- lindsayb610 dev marketing guide (https://github.com/lindsayb610/lindsay-brunner-website/blob/HEAD/content/blog/dev_mktg_guide.md): developer marketing = awareness/activation/adoption/advocacy loops; useful > persuasive; fast path to "hello world"; community over campaigns; developers approve/veto 60%+ of stack decisions; tutorials outperform ad campaigns (one 6-line Node snippet tripled conversions vs paid search).
- emilwareus credibility framework (https://github.com/emilwareus/addcommitpush.io/blob/HEAD/brain/insights/engineering-org-brand/credibility-is-a-costly-to-fake-signal.md): costly-to-fake signals separate competent from incompetent vendors: (1) inspectability — publish source/method/numbers/failures; (2) recurrence — multi-year release cadence w/ green CI; maintenance not release is the credibility mechanism.
- arxiv.org 1908.04219 (https://arxiv.org/pdf/1908.04219): developers promote OSS via blogs (announcements), events/user meetings, Twitter, newsletters/RSS.
- Evidence grade: mostly practitioner case studies + one 2019 paper; no RCTs found.

## Q4 — failure modes of unified content-intelligence loops
- Profit Acuity guide (https://markets.financialcontent.com/dailypennyalerts/article/marketersmedia-2026-7-20-content-marketing-failures-top-mistakes-and-solutions-guide-announced): six recurring failures — no documented strategy (reactive cycles, burnout), undefined audience targeting (generic content), insufficient promotion (one share, unseen), vanity metrics (likes/followers instead of pipeline/revenue), ignoring SEO (undiscoverable, decays fast), marketing-sales-product misalignment (sales never uses assets). Industry data: documented strategy → 350% more likely to report success.
- WTM/Pezz (https://www.wtm.com/portfolio/en-gb/blog/industry-news/data-driven-marketing-vanity-metrics.html): attribution fragmentation — platform pixels don't talk; display + PPC + email all claim same booking; fix: one agreed source of truth for business results; vanity metrics rig the scoreboard.
- Usermaven HubSpot limits (https://usermaven.com/blog/hubspot-attribution-limitations): untracked pages, dark social, offline conversations, ad blockers stay outside attribution; sampling at scale (20M interactions); attribution ≠ incrementality; contact-based not committee-based.
- Attribution mechanics (https://github.com/haonguyen1915/flex-kit/blob/HEAD/flex_kit/packs/disciplines/marketing/skills/marketing-attribution/SKILL.md): the identity graph — join anonymous browsing to conversion via anonymous distinct_id + first-touch props, merge on identify(); most common failure: identify() never called → customers appear from nowhere; stitching third-party-domain conversions via metadata passthrough + webhook identity merge.
- Meta-ads pain point (https://github.com/hulkintherapy/meta-ads-research/blob/HEAD/pain-points/21-knowledge-gap-skill-gap.md): ROAS obsession masks overspend on existing customers; iOS tracking gaps + view-through credit inflate; CPA (channel) vs CAC (business) confusion.
- Disconnected tools: Haugan Cruises/Mautic case — "fragmented tool landscape... no clear statements about added value"; fix was 15 lists → 1 database, unified tracking (https://mautic.org/case-study/haugan-cruises/).
- Marketing automation mechanics: UTM capture must be first-class, attribution built into contact lifecycle (brauliosilveira README).
- Campaign ops: Mautic cron lesson — without mautic:segments:update / campaigns:update / campaigns:trigger, automations silently do nothing (hawkhost).
