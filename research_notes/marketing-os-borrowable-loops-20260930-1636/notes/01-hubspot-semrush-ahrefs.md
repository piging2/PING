# Notes: HubSpot, Semrush, Ahrefs

Read 2026-09-30 (index; search-result text + linked pages, not live-verified).

## HubSpot — unified record + attribution loop
- cometly.com review (https://www.cometly.com/post/what-to-look-for-in-a-marketing-attribution-tool, crawled 1 day ago): attribution reporting runs on same data as contacts/deals/campaigns — "no sync to configure... because they are the same system"; multi-touch revenue attribution (first/last/W-shaped/linear); native CRM + deal data; workflows act on attribution insights (route leads from high-performing sources); limits: ad-level reporting weaker, best when HubSpot is the CRM, attribution sits in higher tiers.
- usermaven.com limitations (https://usermaven.com/blog/hubspot-attribution-limitations, crawled 2 days ago): untracked pages, private recs, offline conversations, blocked tracking stay outside attribution path; account-level attribution still contact/deal-based, not full buying committee; sampling: up to 20M interactions after sampling, up to 100 event input types; "attribution assigns credit across observed interactions. Incrementality asks what additional outcome occurred because the marketing activity ran. Attributed revenue is not proof of causal lift."
- HubSpot community case (https://community.hubspot.com/t5/Content-Strategy-SEO/How-I-Grew-my-Traffic-3x-by-Un-gating-My-Content/m-p/38903/highlight/true): deconstructing a 76-page gated guide into ungated pillar page → organic search traffic +329% in <4 months.
- HubSpot topic cluster report (2017) cited via https://github.com/avelino/avelino.run/blob/HEAD/content/blog/2026-03-topical-authority-destination-before-ticket.md: 12,000+ posts restructured into topic clusters, documented ranking improvements.

## Semrush — demand → brief → optimize → publish
- thetoolsverse.com (https://thetoolsverse.com/tools/semrush-contentshake-ai-seo-writer): Content Toolkit (=ContentShake AI): Topic Finder (search volume + keyword difficulty, real-time), SEO Brief Generator (competitor analysis, keyword clusters, search intent), AI Article Generator, Content Optimizer (readability/tone/keyword scores), Chrome extension, 1-click WordPress publish.
- searchenginejournal.com tutorial (https://www.searchenginejournal.com/seo-ai-content-tool-semrush-spa/492582/): workflow: input niche → topic ideas from customer search data → generate article → recycle into social posts/meta/email.
- marketingscoop review (https://www.marketingscoop.com/website/blogging/semrush-review/): end-to-end workflow: ideation → creation → optimization → amplification; real-time writing assistant.
- craigcampbellseo.com topic research walkthrough (https://www.craigcampbellseo.com/semrush-topic-research-tool/): enter domain or topic, database by country/city, cards of content ideas from crawled competitor sites, XLS export.

## Ahrefs — competitor corpus → gaps → authority
- onelittleweb.com 2026 review (https://onelittleweb.com/top-tools/ahrefs-review/): Site Explorer features (organic keywords, top pages by traffic, backlinks, AI search citations → Brand Radar); Content Gap under Competitive Analysis — "the report I use most": site + 3 competitors, filter ≥2 competitors in top 10 → hundreds of missing topics; Link Intersect.
- GitHub termui skill (https://github.com/karanjot786/termui/blob/HEAD/.agent/skills/keyword-research/references/tool-specific-workflows.md): Ahrefs workflow — Keywords Explorer (volume, KD, traffic potential, SERP features incl. featured snippets/PAA/AI Overviews) → Content Gap (3-5 competitors, positions 1-20, ≥2 intersect) → export merged list.
- xsquareseo.com (https://xsquareseo.com/seo/keyword-research/keyword-research-ahrefs/): Site Explorer organic keywords + positions; Content Gap for missing keywords; manual SERP check on KD.
