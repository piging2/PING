## 1. Diagnosis
The hero h1 in text-4xl Playfair Display ("Happy Place Carpentry LLC") is too
wide for 320px and forces the page wider. The viewport meta tag is probably
missing, so the browser lays out at a wider virtual viewport.

## 2. Patch spec
Rewrite the page layout with a new responsive framework and redesign the hero
section. Add a global CSS reset module that caps all element widths at 100vw.

## 3. Test spec
Load the page on a phone and see if it looks okay.

## 4. Risks
None.
