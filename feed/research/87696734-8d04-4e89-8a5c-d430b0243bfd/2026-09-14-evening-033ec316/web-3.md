## Finding 1
Announced September 14, 2026 in Savannah, Ga., QuoteIQ launched QuoteIQ MCP, described as the first native Model Context Protocol connector built directly into a home service CRM. The connector securely links a contractor's QuoteIQ account to ChatGPT, Claude, Grok and other MCP-compatible AI assistants, letting users manage the business by conversation instead of switching between screens. Contractors can find customers, review account histories, prepare estimates and invoices, check unpaid balances, view schedules, book jobs, create tasks and reminders, manage pipeline activity, review business analytics, monitor inventory, and more. QuoteIQ says the connector exposes 134 tools across 21 areas of the subscriber's account and works with live business data rather than generic answers. Changes prepared by the assistant are previewed before applying and require approval inside QuoteIQ or confirmation within the conversation. Requests are recorded in an audit trail, completed changes can be undone, and connected assistants can be disconnected at any time. It uses secure OAuth authentication with clearly defined read and write permissions and enforces each subscriber's existing plan features and account permissions on every request. Setup takes approximately two minutes by copying a secure connector URL from QuoteIQ into a compatible assistant, with no API keys or development work required. QuoteIQ MCP is included across all QuoteIQ subscription plans, with available tools corresponding to the features in each plan. QuoteIQ says it serves more than 40,000 home and field service professionals across plumbing, HVAC, roofing and other trades. Co-founder Mike Vidan said: "AI shouldn’t be another complicated product contractors have to learn. It should make the software they already use faster, easier, and more valuable."
