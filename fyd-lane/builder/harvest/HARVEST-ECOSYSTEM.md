## What this changes about the SiteSpec contract

1. SiteSpec is a TYPED JSON DOCUMENT (`{ name, theme, blocks[{id, type, variant, props}] }`) that the owner graph, the site planner, and agents all read and write; no surface may hold a second source of truth (OpenPage harvest).
2. Theme is a token set (colors, fonts, radius, spacing), blocks reference it; the renderer resolves tokens, never component code; the three archetype profiles become data/token/rule overlays on ONE design system, not three systems.
3. Block registry owns `type + variant + props` schemas in TypeScript; generated output is validated against schema and rejected on mismatch; agents and humans emit the same document shape (OpenPage + Payload agent-parity harvest).
4. SiteSpec versions carry `_status` (draft/published) and a bounded revision history with restore, mirroring Payload's `versions.drafts`; the ACCEPT step previews a DRAFT vs PUBLISHED diff before apply.
5. The PATCH planner emits TYPED SitePatches against the registry schema; the visual preview is one client of the same patch surface, never a parallel edit path.
6. Schema.org mapping is pinned to vocabulary v30.0 as a versioned translation map with an upgrader diff; v30.1 is UNVERIFIED as of 2026-09-21, so no 30.1 types enter the map (schema.org harvest).
7. The acquisition edge runs Crawl4AI as an untrusted executor: target URLs and egress policy are enforced outside it; every captured page becomes evidence tagged with source URL, observed_at, and crawler version.
8. Internal agent tool calls adopt the MCP v2 stateless shape now (capabilities carried per request, typed results), so adding the real MCP transport later is a swap, not a redesign; v1 SDK is end-of-line at 1.29.0.
9. The product loop stays PROMPT -> PLAN -> GENERATE (SiteSpec JSON) -> PREVIEW -> INSPECT -> PATCH -> PREVIEW -> ACCEPT -> VERSION: generate returns JSON, never code, so no Lovable-style fragility and no Lovable implementation cloning.
10. Dependency posture: zero new runtime dependencies from this harvest; everything above is a contract or shape decision, with MCP v2 SDK and Crawl4AI adoption gated behind their respective lanes.
