# UI Harvest Wired Audit: generated nodes

Date: 2026-09-21. Auditor: FYD UI-harvest lane (subagent).
Method: source inspection of both generated node surfaces
(`src/app/sites/happy-place`, `src/app/sites/coppersmith-plumbing`,
shared client `src/app/sites/_shared/site-client.tsx`,
`src/fyd/components/renderer.tsx`, `src/fyd/components/registry.ts`).
Classification discipline from
`convergence-expansion-2026-09-19/lanes/ui-harvest/REPORT.md`:
WIRED / MOCK / DEAD / UNWIRED / ORPHAN / STALE.

Live-check caveat: the dev server (:3100) was down at audit time, so
wired verdicts below rest on source inspection plus the new executable
gates (`src/fyd/wiring/action-verifier.ts`, probe-gated). Live probes
are listed at the end and must pass before any PASS claim.

## What changed this pass

1. `src/fyd/wiring/action-verifier.ts` (new): the action analog of the
   binding verifier. Every interactive control names a NodeActionId;
   `verifyAction` returns WIRED / DEGRADED / UNWIRED with an honest
   user-safe reason. Unknown actions fail closed. 8/8 tests pass.
2. `src/fyd/ui/` (new): customer-surface shared primitives adapted from
   the harvest spec, not imported from the operator console:
   `evidence-state.tsx` (EvidenceStateLabel: observed/inferred/
   unverified/unknown/unavailable/withheld),
   `fail-closed.tsx` (unreadable renders as Unknown/Unavailable, never
   fake healthy, never silent zero),
   `why-this.tsx` (contextual claim-to-evidence drill-down).
3. `src/fyd/boundary/data-boundary.ts` (new) + `data-boundary.test.ts`:
   Nolan's template/data boundary as executable law. Customer-owned
   (identity, facts, media, content, object graph, SiteSpec, owner
   overrides, evidence history) travels as a portable
   CustomerDataPackage (separable, exportable, deletable); FYD-owned
   (design system, component registry, pipeline, renderer, derivative
   cache) stays shared. Static tests enforce both directions:
   shared code never imports customer paths or hardcodes customer names;
   customer data never imports presentation modules. 6/6 tests pass.
4. Boundary fix: `site-client.tsx` lived under
   `src/app/sites/happy-place/` while Coppersmith imported it across the
   customer boundary (`../happy-place/site-client`). Moved to
   `src/app/sites/_shared/site-client.tsx`; both pages updated.
   Shared infrastructure no longer lives inside a customer namespace.
5. STALE fix: registry described IdentityCard as having "follow and share
   actions" that do not exist. Description corrected to say they are
   unwired.
6. Media discovery (`src/fyd/media/discover.ts`): regex HTML parsing
   replaced with the ecosystem package `node-html-parser` (harvest
   posture). Same output contract; 11 new tests pass.
