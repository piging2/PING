# Interoperability Harvest Matrix

Date: 2026-10-02. Lane: interop harvest, read-only. Branch: `interop/harvest-2026-10-02`.
Binding law: PING owns identity, authorization, policy, canonical events, evidence, approval, outcomes. Standards own interoperability. MCP is an edge, never authority. DISCOVERY IS NOT AUTHORIZATION: an Agent Card never grants authority. One event spine; adapters grow no new ontology.

Binding distinctions: SKILL = how to do something. MCP = how an agent discovers/uses tools, resources and related server capabilities. A2A = how independent agents/systems communicate and coordinate work. FYD CONNECTOR = how PING observes or acts on an external service. PING CAPABILITY = what an actor is authorized to do. PING EVENT = what canonically happened.

Correction applied (Nolan, binding): "zero dependencies, everything stdlib-implementable" is NOT a goal. Prefer official SDKs at the edges; hand-rolling wire protocols decreases optionality by making PING inherit protocol drift.
