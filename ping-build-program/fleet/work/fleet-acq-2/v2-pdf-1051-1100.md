# Acquisition ACQ-1051..1100: documents-pdf cases 100-149 (fleet-acq-2, 2026-09-24)

Boundary-hardening family, second batch. Fixture generator:
`fleet/work/fleet-acq-2/gen_pdf2.py` (50 fixtures under `fx/pdf/case-100..149.pdf`,
manifest `manifest-1051-1100.json`). Same hardened boundary
(`pdf_harness.py`); evidence: `pdf2-evidence.json`.

Fixture-integrity fix applied during this batch: byte-insertion mutations were
initially shifting all downstream xref offsets (broken by construction, not by
adversarial intent). Added `rebuild_xref()` to `gen_pdf.py`, which re-cuts the
xref/trailer/startxref after mutation so the adversarial *feature* (AcroForm,
OutputIntents, /AA, bogus filters, etc.) is what gets tested. Intentionally
malformed cases (truncated, bad offsets, stray objects, line-ending games) keep
their broken form via `rebuild=False`. One generator bug fixed along the way:
startxref initially pointed at the trailer instead of the xref table.

Harness refinement: /OpenAction now quarantines only when the action carries a
dangerous /S type (JavaScript/Launch/URI/SubmitForm/...); a benign GoTo
destination (case 149) parses as bounded success with provenance.
