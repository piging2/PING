# Acquisition ACQ-1001..1050: documents-pdf cases 50-99 (fleet-acq-2, 2026-09-24)

Boundary-hardening family. Fixture generator: `fleet/work/fleet-acq-2/gen_pdf.py`
(50 adversarial PDFs under `fx/pdf/`, manifest `manifest-1001-1050.json`).
Hardened boundary: `fleet/work/fleet-acq-2/pdf_harness.py`; evidence:
`pdf-evidence.json`.

Boundary policy (in order): empty file -> typed failure; over 5 MB -> typed
failure (bounded); missing %PDF header -> typed failure; active-content markers
(/JavaScript, /Launch, /EmbeddedFiles) -> QUARANTINE; /URI annotations and
/OpenAction -> QUARANTINE; encrypted -> typed failure (null credential tried
once, never guessed); page count over 200 -> typed failure; parse/extraction
exceptions -> typed failure with error kind; zero extractable text -> bounded
success with explicit provenance (never "no text found" as a guess).

## Results

  with per-page provenance, or explicit 0-char image-only/blank outcome.
- TYPED_FAILURE x11 (cases 52-56, 61-64, 68, 85): empty, non-PDF, truncated,
  encrypted-without-credential, page/size cap exceeded, binary garbage.
- QUARANTINE x5 (cases 57-60, 76): JS action, launch action, URI annotation,
  embedded files, second URI annotation.

Every fixture ended in a typed outcome; at no point was a parser guess
presented as canonical fact. Parser recovery paths (broken xref offsets,
missing /Root, bad startxref) are recorded in provenance, not hidden.
