Pattern-level sandbox proof. Lab: `fleet/work/fleet-acq-2/crash_ack_lab.py`;
evidence: `crashack-evidence.json`. Write-ahead journal (intent -> apply via
tmp+rename -> ack) with crash injection at each phase and restart recovery.

## case 0 (ORA-3651..3660): crash before ack — PROVEN x10

## case 3 (ORA-3681..3690): kill -9 mid-write, no torn state — PROVEN x10

version. Torn state is structurally impossible — the final path is only ever
