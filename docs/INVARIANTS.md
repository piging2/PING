# Invariants

Executable truths. Every invariant points toward a test.

- worker claim != verified truth
- projection != canonical truth
- agent output != canonical truth
- external observation != owner claim
- provider identity != PING identity
- execution != authorization
- private context != public evidence
- same semantic input must produce deterministic IDs
- same graph + viewer context must produce deterministic render model
- owner correction survives regeneration
- a free endpoint being excellent does not authorize sending it data (DATA CLASS → PROVIDER ELIGIBILITY)
- transport success != mission success
