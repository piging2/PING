# Harvest log

What came from PING, what was adapted, what was rejected, why. Generated from harvest-manifest.json — do not hand-maintain.

Process: DISCOVER → CLASSIFY → PROVE → HARVEST → WRAP → TEST → KEEP OR REJECT.

A primitive counts as harvested when: SOURCE IDENTIFIED, LICENSE ACCEPTABLE, TARGET OWNER IDENTIFIED, DEPENDENCIES BOUNDED, TEST MOVED/ADAPTED, TEST PASSES, CALLER USES IT. No orphan libraries.

See `harvest-manifest.json` for the machine-readable record.
