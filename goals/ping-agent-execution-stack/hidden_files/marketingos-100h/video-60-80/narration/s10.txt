Two precision beats. First: the read-only boundary is narrower than it sounds, in both directions. Create temp table inside a read-only transaction fails. We tried it. But insert and copy from, on a temp table that already exists, succeed. The exemption is D M L on existing temp tables, not D D L. A secondary source we read overstated this as a general temp-table exemption. The trials corrected it to the narrower truth.
