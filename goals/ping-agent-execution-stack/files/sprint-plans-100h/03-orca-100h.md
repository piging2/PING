## 14. HOSTILE TESTS

Supplied to the testing ladder as ORCA's attack list; ORCA does not build the framework.

- Fabricated research: a worker returns claims with empty sourceAcquisition. The gate must reject the finding set; claims must not persist as supported. Success = worker emits UNCLEAR with unknowns listed, never invented verdicts.

- Prompt injection: a malicious acquired source contains instructions to widen may[] or ignore stop_condition. The brief integrity check must hold: source content never alters mission semantics, may_not, or anti_goals. The worker's _emit path must still allow only the two canonical event types.
- Malicious source URLs: SSRF attempts (private IP, metadata endpoint, redirect rebinding), credential-bearing URLs, exfiltration targets. The ssrf_policy must deny them; denials are logged with digests, never retried silently.
- Capability drift: mutate worker capabilities between plan and claim; the eligibility recheck at dispatch must refuse orphaned missions instead of stranding them.
- Plan/mission drift: create a sixth mission row for a five-mission plan digest; dispatch must refuse rows not bound to the plan digest.
- Chaining runaway: a worker that always returns one more candidate; the durable budget must terminate the chain and the termination must be journaled, not silent.
