## THE BIG UPGRADE: BUILD THE INTELLIGENCE GRAPH, NOT A CONTENT CALENDAR

Every artifact downstream of a structured argument. A video/post/article must answer: THESIS → CLAIMS → SUPPORT SET → COUNTEREVIDENCE → VERDICTS → SOURCES → AUDIENCE PROBLEM → NOVELTY / SURPRISE → CREATIVE DECISION → DISTRIBUTION HYPOTHESIS → OUTCOME → LEARNING. This is the moat. The content itself is a projection.

1. RESEARCH ENGINE: BUILD A REAL CLAIM MACHINE. First MarketingOS primitive: INTELLIGENCE_RESEARCH on existing mission runtime. Inputs: questions[], claims_to_verify[], evidence_requirements, counterevidence_requirements, audience_context, output_schema, synthesis_rule. Returns structured findings, not an essay. Every material claim gets: claim_id, claim_text, verdict, support_set[], counterevidence[], source_quality, verification_state, confidence, applicability, freshness, unknowns[]. Keep source quality separate from verification. Do not collapse PRIMARY SOURCE / LIVE OBSERVATION / CONTROLLED REPRODUCTION / INDEPENDENT CORROBORATION / VENDOR CLAIM / MODEL INFERENCE / UNKNOWN into one fake confidence score. CONFIRMED ≠ PLAUSIBLE ≠ INFERRED ≠ UNCLEAR ≠ REFUTED. Model intelligence discovers and synthesizes. Evidence establishes what can be claimed.

2. CONTRADICTION ENGINE. Actively search for reasons the thesis is wrong. Every important research mission asks: WHAT SUPPORTS THIS? WHAT CONTRADICTS THIS? WHAT ALTERNATIVE EXPLANATION FITS? WHAT WOULD FALSIFY IT? WHAT EVIDENCE ARE WE MISSING? No ContradictionAuthority. Bounded analysis over claims/evidence. Strong artifacts expose disagreement rather than laundering uncertainty into persuasive prose.

3. NOVELTY ENGINE. Stop equating "technically correct" with "worth publishing." Surprise structure: EXPECTED BELIEF → OBSERVED REALITY → GAP → MECHANISM → CONSEQUENCE. The engagement incident works because "a human reviewed every action" was the expected safety condition, yet two ineligible effects escaped. The lesson is not Facebook likes. It is: review is not enforcement. The repaired system replayed 34 candidates (25 ineligible, 9 eligible, zero mismatches) plus 12/12 adversarial. That proof dominates the story. Facebook is merely the experimental apparatus.

Clusters: building agents with external effects; debugging distributed worker systems; making agent authorization trustworthy; running local/edge AI infrastructure; building evidence-grounded AI systems; operating autonomous software in production. A person can inhabit several clusters. Per cluster learn: PROBLEMS, QUESTIONS, BELIEFS, MISCONCEPTIONS, VOCABULARY, PROOF EXPECTATIONS, OBJECTIONS, CONTENT CONSUMPTION, ACTION PROPENSITY. Never make audience inference authority. Revisable evidence-backed projection.

Evaluate independently: AUDIENCE PAIN, EVIDENCE STRENGTH, SURPRISE DELTA, TECHNICAL DEPTH, TIMELINESS, COMPETITIVE SATURATION, DEMONSTRABILITY, REPRODUCIBILITY, IDENTITY VALUE, DISTRIBUTION FIT, CONVERSION RELEVANCE. Preserve the component vector; do not blend into one magic number.

Output is not "news." Extract: NEW CAPABILITY, NEW CLAIM, NEW FAILURE, NEW BENCHMARK, NEW TECHNIQUE, NEW CONTROVERSY, NEW DEMAND SIGNAL, NEW LANGUAGE, NEW UNSOLVED PROBLEM. Connect to existing knowledge and experiments.

Every derivative inherits the same claim/evidence lineage. Channel adaptation may change framing/length/vocabulary/opening. It may not change factual truth. MarketingOS analogue of FYD's OBJECT GRAPH ≠ WEBSITE: KNOWLEDGE / THESIS ≠ CONTENT ARTIFACT.

8. CLAIM LINTER BEFORE PUBLICATION. Before Nolan sees a proposed artifact, extract every externally checkable claim. For each: SUPPORTED / PARTIALLY SUPPORTED / CONFLICTED / INFERRED / UNSUPPORTED / STALE. Flag: unsupported superlatives, causal claims from correlation, benchmarks without comparable conditions, current-state claims on stale evidence, vendor claims as independent findings, anecdotes generalized to universal rules, security claims stronger than the reproduction. 9. REPRODUCIBILITY AS CONTENT. Evidence becomes part of the artifact: EXPERIMENT, SETUP, EXPECTED, OBSERVED, COUNTEREXAMPLE, LIMITATIONS, REPRODUCTION PROCEDURE. A piece should tell a skeptical engineer exactly what observation would falsify it.

10. DISTRIBUTION IS AN EXPERIMENT, NOT A BROADCAST. Every distribution action needs a hypothesis. Record: ARTIFACT, AUDIENCE, CHANNEL, ANGLE, HOOK, FORMAT, TIMING, CTA, EXPECTED SIGNAL, GUARDRAIL, OBSERVATION WINDOW. Ingest the result. Never let "published" mean "successful." Preserve: PROPOSAL ≠ AUTHORIZATION ≠ ATTEMPT ≠ RESULT ≠ EFFECT ≠ VERIFICATION ≠ OUTCOME.

11. METRICS NEED SEMANTICS. Separate: ATTENTION (impressions, views, completion); ENGAGEMENT (comments, saves, shares, profile visits); QUALITY (substantive replies, technical corrections, citations, qualified follows); INTENT (repo visits, site visits, demos, inbound questions); BUSINESS (qualified conversations, opportunities, revenue); TRUST (correction rate, unsupported-claim rate, retractions, source quality). Optimize a vector, not vanity engagement.

12. COMMENT INTELLIGENCE. Comments are sensors. Classify: AGREEMENT, COUNTEREXAMPLE, CORRECTION, QUESTION, OBJECTION, IMPLEMENTATION EXPERIENCE, ALTERNATIVE, REQUEST. High-quality disagreement becomes research input. Route: COMMENT → OBSERVATION → CLAIM → VERIFY → LEARNING → NEXT ARTIFACT.

13. LEARNING MUST BE CAUSALLY HUMBLE. Never encode "Hook X caused performance" from one post. Record: OBSERVATION, POSSIBLE EXPLANATIONS, CONFOUNDERS, HYPOTHESIS, NEXT TEST. Promote a rule only after sufficient repeated evidence: OUTCOME → CANDIDATE LEARNING → SUPPORT SET → APPLICABILITY → CONFIDENCE → PROPOSAL → HUMAN/POLICY PROMOTION. Never: one good post → permanent playbook rule.

WHAT IS UNKNOWN? WHAT WOULD FALSIFY IT? WHO MIGHT CARE? WHAT ARTIFACT DID WE PROPOSE? WHICH CLAIMS SURVIVED VERIFICATION? WHAT DID NOLAN AUTHORIZE? WHAT ACTUALLY EXECUTED? WHAT EXTERNAL EFFECT WAS VERIFIED? WHAT OUTCOME DID WE OBSERVE? WHAT DID WE LEARN? Unknown renders as UNKNOWN. Mission Control remains a projection, never authority.
