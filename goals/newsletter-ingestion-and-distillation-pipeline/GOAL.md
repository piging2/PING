# Newsletter ingestion and distillation pipeline

Goal ID: goal_4c988e48a0d2
Goal slug: newsletter-ingestion-and-distillation-pipeline

## Description
Daily ingestion of Nolan's learning-suitable newsletters from Yahoo mail into the PING event spine as learning-domain observations, plus a local distillation loop that summarizes each issue as a derived digest with full provenance. Mailbox stays read-only, credentials stay sealed, newsletter content is treated as untrusted external input.
