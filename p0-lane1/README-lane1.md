## Classification guidance for the real codebase

- gateway/server.js and the bootstrap composition planes: REQUIRED_RUNTIME.
- ping-runtime/events/legacy_ingress_adapter.js: LEGACY_REQUIRED (task
  directive; the refactor requires it at top level).
- Optional capability providers (6374519f8 isolation pattern): OPTIONAL_RUNTIME,
  declared via --dynamic-targets so lazy require(variable) targets stay
  classified without becoming mandatory.
- gateway/generated/*_generator.js and GENERATOR_DETERMINISM.md scope:
  BUILD_ONLY. If a runtime entrypoint reaches them, the checker fails loudly;
  that is a composition defect, not a checker defect. (Generator files were
  not touched; the fixture does not include them.)
- gateway/generated/*.json registries the gateway requires at boot:
  REQUIRED_RUNTIME data files; their generators stay BUILD_ONLY.
- Tests, evals, archives: TEST_ONLY / PRESERVED_NOT_DISTRIBUTED; reachable
  from an entrypoint they fail certification.
- Unlisted reachable modules: UNKNOWN -> certification fails. Classify or
  exclude; do not leave UNKNOWN.

## Seam contract the smoke test needs from the real code

gateway-smoke.js requires the snapshot's runtime module to export GatewayRuntime
(or a boot factory) with `initialize({ mode: 'smoke' })` stopping at a
declared safe boundary (composition wired; no listen(), no DB connect) and a
`shutdown()` that releases what initialize acquired. The fixture implements
this contract; the REAL GatewayRuntime must be verified to expose an
equivalent boundary before the harness is trusted against it. The harness
never patches Module._load: module resolution is real or the test is void.
