## Hunt-parser lessons (for reuse)

- WHERE-clause and JOIN column references are reads; SELECT-list-only scanning produces false read-never flags.
- Dynamic `UPDATE t SET ${fields.join()}` with a JS allowlist is a write; scan allowlists.
- Multi-line SQL (SET on the next line) defeats single-line UPDATE regexes.
- `now()` / `nextval()` column defaults are writes-by-database.
- `SELECT *` is not evidence of a specific column read.
