# Angle performance (closed-loop learning)

Rolling tally of signal -> outreach angle -> channel -> response -> outcome. Updated by every engine sweep from responses.md and the follow-up log. Optimize toward qualified conversation -> meeting -> customer -> revenue, never toward opens, clicks, or follows.

## How to log
Each round appends one row per outreach batch sent (initials, F1, F2, review-triggered). Outcome is filled when known: no_response, reply_positive, reply_neutral, reply_negative, meeting, customer.
