## Can a fresh orchestrator choose a capability from this structure today?

Honestly: mostly yes for the scheduled and scripted work, partially no for Pig-side ops.

What is queryable from durable artifacts today:
- "Which capability for X?" for Pig-substrate work: `pig-capabilities.json` (machine-readable, contract-tested; fix the file, never the implementation).
- "Which capability for X?" for campaign work: the six cron bodies are the executable specs (id, schedule, authority notes, step-by-step procedure). This document is the human/machine index over them.
- "What inputs?": script usage lines (`emit-observation.py <brief_id> <observation>`, `run_pass.sh <job.json>`, `new-job.sh <slug>`, `mark-verified.sh <answer-file> --by <who>`), implemented_by/input fields in the manifest, cron step text.
- "Who owns it?": cron frontmatter `owner: goal:ping-social-outreach-campaign`; capability rows above; AGENTS.md standing directives (STAY-ON rules, channel priority).
- "What did the last run do?": runs.jsonl ledger, sweep summaries, engagement logs, reconcile.py LATEST.json. Fresh-agent reconstruction from artifacts alone was verified live 2026-09-14.

What still requires tribal knowledge:
- Pig-side Windows ops that have no cloud representation: the PigiFBLogin watchdog task config, the PigiGatewayWatch task config, the Chrome profile path, the fb-engage inbox layout. Cloud agents can only rediscover these by SSH probing.
- Nolan's manual steps (logging into Meta AI or Facebook in the headed Chrome after a session loss) are documented in prose, not as procedures a machine can execute.
- The cron bodies are markdown prose, not machine-parseable contracts: no contract test can assert "step 4e still does the DISTILL decision." Only pig-capabilities.json has that enforcement.

The single smallest missing projection: a pig-capabilities.json-style discovery projection (versioned JSON, contract-tested like test-capabilities.py) for the six outreach-campaign crons and the tandem/skill-CLI script set, so "which capability for X" outside the Pig substrate is answerable from a machine file rather than prose.
