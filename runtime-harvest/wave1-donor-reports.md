## Lane A - Talos (authority kernel) - completed 2026-09-28

Repo: https://github.com/talos-kernel/talos @ 8938f8958e304f96da87b4f5154c4bc3a2b4cfa2 (2026-09-25), 0.19.23-alpha, MIT, Python 3.11+.

Architecture: talos/policy.py (deterministic PolicyKernel, default-deny, no LLM), talos/capability.py (CapabilityMint: HMAC-signed single-use 30s capability tokens), talos/executor.py (fail-closed: decide -> write-ahead exec.intent -> bind snapshot -> recheck -> mint token -> run via GrantedRunner -> receipt), talos/approval.py (human approval round with TTL, parked request fingerprinting, atomic claim), talos/autonomy.py (governor levels 0-5, only tighten never loosen), talos/verifier.py (TOCTOU realpath+sha256 binding before/after), talos/eventlog.py (append-only hash-chained SQLite WAL log, idempotency keys), talos/anchor.py (external head-anchor against tail truncation), talos/manifest.py (immutable tool registry: effect/read-write-exec/reversibility), talos/snapshot.py (pre-run file snapshots for undo), talos/outcome.py (post-run honesty note derived from the log, not the model's narrative).

Mechanism: 1. Model emits proposal (pure syntax repair, zero authority). 2. Executor.run() calls PolicyKernel.decide(req) on ToolRequest (tool, Principal identity, args, targets); fixed pipeline: unknown tool = DENY; missing env = DENY; tool-without-target-extractor = DENY by construction; Tier B system prefixes = DENY; identity not in allowlist = DENY; secret targets = DENY read / NEEDS_HUMAN write; persistence prefixes = NEEDS_HUMAN write. Targets are kernel-derived (guard_targets: realpath-expanded, extractor-based), never model-declared. 3. Write-ahead exec.intent event appended to hash-chained log BEFORE any effect. 4. Executor snapshots kernel-derived targets, binds them (realpath+sha256), rechecks immediately before running; drift = fail-closed BINDING_CHANGED + restore. 5. CapabilityMint re-decides itself (self._policy.decide(req)) at issue time, does not trust executor's verdict. On ALLOW/approved-NEEDS_HUMAN mints Grant: HMAC-SHA256 over (grant_id, tool, action_fp, issued/expires, human_approved flag, governor level), 30s TTL, single-use (grant_id in _spent), fingerprint = sha256 over canonical JSON of (tool, identity, args, declared targets, kernel-derived targets). Any single changed byte fails fingerprint at redeem. 6. ONLY execution path is GrantedRunner.__call__(req, grant): redeems token first (signature, TTL, governor-level match, tool match, fingerprint match, single-use), then dispatches. Raw runners disappear into GrantedRunner; DENY can never produce a token anywhere in the process. 7. NEEDS_HUMAN parks exact request object with target fingerprint, 5-min TTL; operator "yes" narrow affirmative set ("yes"/"ja" only); "always" creates standing rule on exact (harness, subcommand) or (host, command) key; /stopall discards approvals in DENY direction. 8. After execution, exec.result receipt with grant_id; outcome.note() derives run summary from event log, not model narrative.
